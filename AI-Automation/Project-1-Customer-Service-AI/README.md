# Project 1: AI-Powered Customer Service Assistant

## Project Overview
This project explores how Artificial Intelligence can support customer service by understanding customer enquiries and generating helpful responses.

## Problem Statement
Businesses receive many customer enquiries about deliveries, returns, complaints and general questions. Responding manually can take time.

This project aims to demonstrate how AI can help organise enquiries and suggest suitable replies.

## Project Objectives
- Understand how AI can process customer messages.
- Categorise enquiries automatically.
- Generate suggested customer service responses.
- Identify enquiries that need human attention.
- Explore workflow automation.

## Tools and Technologies
- ChatGPT
- AI prompting
- Make or n8n (planned)
- Google Sheets (planned)
- JavaScript (planned)

## Proposed Workflow
1. Customer submits a message.
2. AI analyses the message.
3. AI identifies the enquiry category.
4. AI generates a suggested response.
5. A human reviews sensitive or complicated cases.
6. The enquiry is stored for tracking.
